# 第十课 · 10.1：用 FastAPI 提供问答接口

以前在命令行输入问题，这节改成让程序通过 **HTTP 请求**来提问。FastAPI 接收问题，再交给已有的知识 Agent。

本节只在自己的电脑运行。沿用 414 个知识块和已有向量，启动时读取它们，不重新生成向量。

## 1. 安装并启动

在 PowerShell 执行：

```powershell
Set-Location -LiteralPath 'E:\agent Perfect form\knowledge-agent'
uv run python 'C:\Users\Zwb\Documents\Codex\2026-10-06\n-h-2\outputs\knowledge-agent\install_lesson10a.py'
```

启动前可选运行 `uv run python lesson10a.py --check`：检查配置、知识块与已有索引，并连接 Redis 和 MCP；不调用云端模型，也不执行计算。

然后启动接口：

```powershell
uv run python lesson10a.py
```

看到服务启动成功后，**保留这个窗口**。程序会读取项目 `.env` 中的模型配置和密钥；发问时不用发送密钥。

浏览器打开 [接口调试页面](http://127.0.0.1:8000/docs)。它是测试接口的页面，还不是聊天网页。

展开 `GET /health`，点 **Try it out → Execute**。HTTP 状态码 `200` 表示这次请求成功。

健康检查确认服务状态和 Redis 连接，不调用 Qwen 或 MCP。模型与工具是否正常，要通过下面的实际问答验证。

## 2. 发出第一道问题

展开 `POST /chat`，点 **Try it out**，把请求正文替换成：

```json
{
  "session_id": "api-study",
  "question": "根据笔记解释贴现是什么，再计算票面金额10000元、年贴现率3%、剩余90天的贴现利息，按一年360天计算。"
}
```

点 **Execute**，等待回答。应看到贴现的解释、笔记来源和 **75.00 元**的利息。

返回结果也是 JSON，可以先把它理解成“字段名称和对应值”：

| 字段 | 含义 |
| --- | --- |
| `session_id` | 这次问答属于哪个会话 |
| `answer` | Agent 的回答正文 |
| `sources` | 本轮检索得到、可供核对的笔记来源 |
| `used_tools` | 本轮实际使用的工具 |
| `selected_skill` | 本轮选择的 Skill，可能是 `none` |

来源编号可以帮助核查，但仍要确认原文确实支持回答。`none` 只表示没有选择 Skill，不妨碍查笔记或使用计算器。

## 3. 接着问，再看历史

仍在 `POST /chat`，改成下面的正文后再次点 **Execute**：

```json
{
  "session_id": "api-study",
  "question": "其他条件不变，改成180天，利息是多少？"
}
```

相同的 `session_id` 会接着这个会话。历史帮助补全金额、利率等条件，结果应为 **150.00 元**。这轮可以只调用计算器，`sources` 为空也正常。

展开 `GET /sessions/{session_id}/history`，点 **Try it out**，填入 `api-study`，再点 **Execute**，可查看最近三轮已完成问答。

`session_id` 是本地实验的历史编号，不是用户身份或登录凭证。10.1 使用独立的历史前缀，不会读取 9.3 的会话记录。

## 4. 调试页面打不开时

`/docs` 需要加载在线的页面资源。如果页面空白，可以另开 PowerShell，直接向同一个接口发请求：

```powershell
$requestBody = @{
    session_id = 'api-study'
    question = '根据笔记解释贴现是什么，再计算票面金额10000元、年贴现率3%、剩余90天的贴现利息，按一年360天计算。'
} | ConvertTo-Json
$requestBytes = [System.Text.Encoding]::UTF8.GetBytes($requestBody)
Invoke-RestMethod -Method Post -Uri 'http://127.0.0.1:8000/chat' -ContentType 'application/json; charset=utf-8' -Body $requestBytes
```

查看健康状态和历史：

```powershell
Invoke-RestMethod 'http://127.0.0.1:8000/health'
Invoke-RestMethod 'http://127.0.0.1:8000/sessions/api-study/history'
```

## 5. 这节只记住这些

**GET 用来读取；POST 用来提交问题。** 请求正文中的 `question` 是输入，响应中的 `answer` 是输出。HTTP 状态码说明请求处理情况，不是回答内容。

```text
浏览器或其他程序 → HTTP 请求 → FastAPI → LangGraph 知识 Agent
                                              ↓
                                查笔记 / MCP 计算 / Redis 历史
                                              ↓
浏览器或其他程序 ← JSON 响应 ← FastAPI ← 最终结果
```

FastAPI 检查请求、组织响应；LangGraph 执行已有流程；MCP 仍负责工具通信。先读 [lesson10a.py](<E:/agent Perfect form/knowledge-agent/lesson10a.py>) 的接口，再看 [lesson10a_runtime.py](<E:/agent Perfect form/knowledge-agent/lesson10a_runtime.py>) 怎样连接已有 Agent。

常见状态码：`200` 成功；`422` 输入不符合要求；`409` 已有问题正在处理；`502` 问答未能正常返回；`503` Redis 不可用或服务尚未就绪。本课用单进程，一次处理一道问题。

遇到 `502` 时，先查看会话历史，再决定是否重试。有时回答已经保存，只是在 MCP 连接关闭时发生了错误。

服务只监听本机 `127.0.0.1`。在启动窗口按 **Ctrl+C** 停止 API，Redis 中的历史仍然保留；下次启动后，使用相同的 `session_id` 可以继续聊。
