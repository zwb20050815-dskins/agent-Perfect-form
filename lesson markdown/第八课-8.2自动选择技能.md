# 第八课 · 8.2：让模型自动选择技能

8.1 由你用 `--skill` 指定工作方法；8.2 增加一个选择步骤：**模型先看完整问题和技能摘要，选中技能后，程序才读取它的正文。** 本课不再提供 `--skill` 参数。

现有一个 `bank-study` 技能，再加上“不加载技能”的 `none`，就能演示自动选择。`none` 仍能使用查笔记和计算器，只是不追加技能正文。

## 1. 安装和检查

在 PowerShell 执行：

```powershell
Set-Location -LiteralPath 'E:\agent Perfect form\knowledge-agent'
uv run python 'C:\Users\Zwb\Documents\Codex\2026-10-06\n-h-2\outputs\knowledge-agent\install_lesson08b.py'
uv run python lesson08b.py --list-skills
uv run python lesson08b.py --check
uv run python lesson08b.py --check-redis
```

`--list-skills` 只列名称和描述。`--check` 检查目录元信息、本地配置、知识块、索引和图；两者都不联网。此时尚未读取和校验技能正文，正文会在选中后处理。

`--check-redis` 检查 Redis 连接并初始化 checkpoint 索引，不调用模型。这些检查不代表云服务已经验证成功，也不能保证模型始终选对技能。

本课沿用 8.1 的技能正文、现有 24 个笔记向量、密钥配置和依赖，无需为自动选择重新修改或生成它们。

## 2. 连续做两轮，再试一句问候

第一轮使用默认完整例题：

```powershell
uv run python lesson08b.py --session study
```

省略问题时，程序会问：“根据笔记解释贴现是什么，再计算票面金额10000元、年贴现率3%、剩余90天的贴现利息，按一年360天计算。”每条命令只问一次，**不是进入交互模式**。

预期选择 `bank-study`，然后调用 `search_notes` 和 `calculate_discount_interest`。解释应引用本轮笔记，计算结果为 `10000 × 3% × 90 ÷ 360 = 75.00 元`。

命令结束后，用同一个会话继续追问：

```powershell
uv run python lesson08b.py --session study "其他条件不变，改成180天，利息是多少？"
```

先观察 `[prepare]` 输出的完整问题，确认金额、利率和360天制被保留，天数改成180。预期自动选择 `none`，只调用计算器，得到 `150.00 元`；这轮不必重新讲解概念或检索笔记。

再用另一会话试普通问候：

```powershell
uv run python lesson08b.py --session greet "你好。"
```

预期选择 `none` 并直接回答，不需要调用工具。**选技能和选工具是两次不同的决定**：前者挑工作方法，后者决定执行什么操作。

这些是预期行为，运行时要核对 `[select_skill]` 的选择日志和工具请求。模型可能选错；若返回未知技能名或非法 JSON，程序会停止本轮，不会悄悄改成 `none`。

## 3. 为什么先补全问题，再选技能

```text
START → prepare → select_skill → agent → remember → END
```

`prepare` 利用历史把追问补成完整问题；`select_skill` 只收到这个完整问题和目录中所有技能的 `name`、`description`，不会收到所有技能正文，也不负责回答或调用工具。

选中 `bank-study` 后，`agent` 才读取它的正文，补充到工具模型的基础规则后，继续运行之前的工具循环。选中 `none` 时跳过正文加载，基础规则和两个工具仍然可用。

扫描目录时，程序读到 `SKILL.md` 顶部元信息的结束分隔符就停止。**元信息用于选择，正文用于指导后续工作**；只在需要时读取选中正文，这就是本课的按需加载。

每轮都会重新选择。8.2 的会话按自己的 Redis 前缀和会话编号保存，因此同一个 `study` 即使前后选了不同技能，历史也连贯。8.1 为了人工对照按技能名隔离历史，两课的规则不同，已有课程记录仍保留。

```powershell
uv run python lesson08b.py --session study --history
uv run python lesson08b.py --graph
```

`--history` 只读取 Redis 历史，不调用云 API。`--graph` 不联网，可以看到新增的 `select_skill` 节点。目录非空时，每轮通常比 8.1 多一次 Qwen 技能选择调用。

## 4. 代码先看三处

| 代码 | 作用 |
| --- | --- |
| `lesson08b_catalog.py` 的 `discover_skills()` | 扫描技能目录，只读取名称和描述 |
| `lesson08b_catalog.py` 的 `choose_skill()` | 把完整问题和摘要交给模型，并校验返回的选择 |
| `lesson08b.py` 的 `build_graph()`，以及 `select_skill()`、内部 `agent()` | 串联先选择、后读正文、再执行工具的顺序 |

这仍是项目内的最小技能加载器。技能负责工作方法，知识依据来自本轮检索，数字来自计算器；加载技能不会自动执行其中的脚本。
