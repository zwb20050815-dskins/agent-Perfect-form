## 2. 连续问两轮

第一轮运行默认例题：

```powershell
uv run python lesson09c.py --session mcp-study
```

默认问题是：根据笔记解释贴现，再计算票面金额 **10000 元**、年贴现率 **3%**、剩余 **90 天**的贴现利息，按一年 **360 天**计算。

观察输出：应该查到笔记、调用 MCP 计算器，并得到 **75.00 元**。解释部分应有来源编号，可以对照笔记原文核查；有编号仍需要确认原文确实支持这句话。

第二轮沿用同一个会话：

```powershell
uv run python lesson09c.py --session mcp-study '其他条件不变，改成180天，利息是多少？'
```

这次应得到 **150.00 元**。历史帮助模型补全金额、利率和计息规则；仅修改天数时，可以直接调用计算器，无须重新解释贴现。

两次计算都采用题目指定的公式：`贴现利息 = 票面金额 × 年贴现率 × 天数 ÷ 360`。

查看这个会话已保存的历史：

```powershell
uv run python lesson09c.py --session mcp-study --history
```

9.3 使用独立的历史前缀。即使会话名称相同，也不会读到 8.2 或日常入口保存的历史；9.3 内部使用相同的 `--session` 才会接着聊。

## 3. 两个工具，执行位置不同

```text
读取 Redis 历史 → 补全问题 → 选择并加载 Skill → Qwen
                                                   ↓
                                               选择工具
                                    ┌──────────────┴─────────────┐
                                    ↓                            ↓
                            search_notes                   MCP 计算器
                         当前 Python 进程检索            Server 进程计算
                                    └──────────────┬─────────────┘
                                                   ↓
                                          结果交回 Qwen → 回答
                                                           ↓
                                                    保存到 Redis
```

模型可以按需多次调用工具。**工具说明都交给模型，不代表所有工具都经过 MCP。**

| 工具 | 怎样执行 |
| --- | --- |
| `search_notes` | 在当前进程中完成向量检索、BM25、RRF 和 Rerank |
| `calculate_discount_interest` | 客户端通过 MCP 发出请求，由服务端进程执行计算 |

Skill 仍然提供工作规范，不执行工具。选到 `none` 时，模型仍然能查笔记和计算。

MCP 连接在本轮执行期间保持打开，结束后清理服务端子进程。Redis 是独立服务，`AsyncRedisSaver` 负责把流程状态保存进去；关闭 MCP 连接不会删除 Redis 中的历史。

## 4. 读代码只看这三处

1. **`lesson09c_tools.py` 的工具组合与循环**：把本地 `search_notes` 和 MCP 计算器交给模型，再走“模型 → 工具 → 模型”。
2. **`lesson09b_mcp.py` 的 `open_mcp_tools()`**：复用上一节的连接和代理工具，让计算请求到达服务端。
3. **`lesson09c.py` 的流程与连接范围**：串起问题补全、Skill、工具循环和保存历史，让 MCP 连接覆盖整轮执行。

`await` 用来等待异步操作完成；`ainvoke()` 执行异步流程；`AsyncRedisSaver` 配合异步图保存和恢复状态。它们不会改变检索算法，也不会增加新的知识向量。

想单独看流程，可运行 `uv run python lesson09c.py --graph`，不需要读取配置或连接服务。
