# 第二课：把笔记整理成 Markdown

目标：转换 `银行会计重点笔记.html`，保留标题、表格和来源。这是知识入库的第一步；转换完成后，模型还不会自动读取它。

## 1. 先记住三个概念

- **解析**：从网页标签中取出正文、标题和表格。
- **Markdown**：一种简单的文本格式，`#` 表示标题，`**文字**` 表示加粗。
- **来源信息**：记录内容来自哪个文件、哪个章节，方便以后回答时标注出处。

本课流程：`读取 HTML → 清理网页装饰 → 转 Markdown → 保存正文和来源`。

## 2. 运行脚本

在 PowerShell 执行：

```powershell
Set-Location -LiteralPath 'E:\agent Perfect form\knowledge-agent'
uv sync --python 3.12
uv run python lesson02.py
```

新增两个包：`beautifulsoup4` 负责解析 HTML，`markdownify` 负责转换格式。本课不调用模型，不需要 `.env`。

脚本默认读取桌面“笔记”文件夹里的原件，生成：

```text
data/markdown/
├── 银行会计重点笔记.md     ← 笔记正文
└── 银行会计重点笔记.json   ← 文件、章节等来源信息
```

重复运行会更新这两个生成文件，原 HTML 保留。图片仅保留原来的网络链接与文字说明，本课不下载图片，也不提取图中文字。

## 3. 对照结果检查

用编辑器打开 `.md` 和 `.json`，再与原 HTML 对照：

1. 正文有 **8 个章节、7 张表格、4 个图片链接**。
2. 能找到“会计四大基本假设”的表格，列与内容对应正确。
3. 原来的彩色重点变成了加粗。
4. JSON 中有 `source_file`、`source_path` 和 `sections`，知道内容从哪里来。

正文可读、表格完整、来源明确，就完成了本课。转换只整理原文，不代表已经核实笔记中的知识是否正确。

## 4. 读懂代码的四步

打开 `lesson02.py`，按代码里的 1–4 注释阅读：

| 代码 | 在做什么 |
| --- | --- |
| `source.read_bytes()` | 读取原文件 |
| `BeautifulSoup(...)`、`decompose()` | 理解 HTML 结构，移除不需要的元素 |
| `metadata = {...}` | 整理来源信息；其中 `source_sha256` 是识别文件内容变化的“指纹” |
| `markdownify(...)`、`write_text(...)` | 转成 Markdown，再写入文件 |

想换另一份 HTML，可以传入文件路径：

```powershell
uv run python lesson02.py --source 'C:\Users\Zwb\Desktop\笔记\银行经济学重点笔记.html'
```

这份脚本适用于本课这种结构清楚的 HTML。换文件后也要对照原文检查，尤其是表格和图片。
