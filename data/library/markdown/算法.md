  程序是对算法的具体实现
  程序 = 算法+数据结构
  数据结构通过算法实现
  算法依照数据结构设计程序
  算法有五种特性：
  有穷性：每一个算法都是在执行有穷步之后，在有穷时间内实现
  确实性：每一条指令都只有一个明确的含义，不具备二意性，只有唯一的执行路线，相同
  的输入只能得到相同的输出
  可行性：可以被执行
  输入：相关数据元素
  输出：结果
  算法设计的要求：
  正确性 可读性 健壮性（鲁棒性）   高效性
  健壮性：完整！  对于不同情况有不同的输出与处理结果     不是中断程序而是输出一个特殊
  的值
  算法的时间效率：程序执行所消耗的时间
  两种衡量方法：事后统计：跑完程序     对时间效率等性能多方面评估（算法实现和测算时间
  和空间开销）
  事前预测：在程序运行前对时间效率等性能多方面预测（对算法所消耗资源预测）
  事前分析方法：算法运行时间    = 求和（每条语句的执行次数   * 执行一次时间）

  为了快速估计：只比较最高数量级

 分为单链表、双链表、循环链表
 单链表：头指针   头结点（可有可无）    第一个结点加指针域
 链表是线性表的链式存储映像称为线性表的链式存储结构
 带头结点示例：

 指针域用来存储后继元素的地址
 双链表：
 两个指针域夹一个数据元素
 前一个指针域放前继元素的地址      后一个则为后继元素的地址
 循环链表：首尾相接的称为循环列表

 1. 头指针：
•就是一个指针变量，比如      Node* head
•只有地址值，没有数据域和指针域
•无头结点时：head == NULL表示空表
•有头结点时：head  指向头结点
 2. 头结点：
•是链表的第一个结点（不存真实数据）
•有数据域（可能存长度等）和指针域
 有头结点时：head->next == NULL表示空表

 3. 循环链表的核心：
•尾结点的指针域指向第一个结点（或头结点）
•不是指向头指针变量本身
•形成环状结构
 头指针是指针变量，头结点是特殊结点，循环链表尾结点指向第一个结点而不是头指
 针。学算法时用Python入门最快。

 有头结点就在头结点加空字符     没有头结点就在头指针加空字符
 头结点可以存放表的长度    头指针是存放第一个结点的地址的
 头结点 = 第一个结点
 有头结点好处  第一个位置的操作域后续一样     方便不用特殊处理
 无论头结点是否为空，头指针就是指向头结点的非空指针
 头结点的数据域可以存放表的长度值也可以为null
 结点在存储器中的位置是任意的，单在逻辑上相邻的数据元素不一定相邻
 只能通过头指针进入链表    通过指针域来定位每一个数据元素的位置       但是数据元素的数
 量不等 所以第一个结点到最后一个元素的时间不等这叫做顺序存储法
